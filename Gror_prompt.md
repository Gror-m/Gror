## DESIGN LANGUAGE & AESTHETIC

### Core Visual Elements

**1. Premium Glassmorphism**
- Frosted glass panels with subtle borders
- Background blur effect (backdrop-filter: blur(12px))
- Semi-transparent layers: `rgba(255, 255, 255, 0.08)` to `rgba(255, 255, 255, 0.12)`
- Premium depth through shadows: `0 8px 32px rgba(107, 44, 145, 0.12)`
- Refined border: `1px solid rgba(214, 180, 162, 0.3)`

**2. Luxury Spacing & Typography**
- Breathing room: generous padding (48px - 96px sections)
- Line height: 1.6 - 1.8 (premium readability)
- Letter spacing: +0.5px to +1px (elegant, expensive feel)
- Font stack: Prefer high-end typefaces (Inter, Poppins, Space Grotesk, or premium serif like Crimson Text)
- Hierarchy: Clear size contrast (48px hero, 32px section titles, 16px body)

**3. Premium Shadows & Depth**
- Soft ambient shadows: `0 12px 40px rgba(107, 44, 145, 0.08)`
- Elevated card shadows: `0 20px 60px rgba(107, 44, 145, 0.15)`
- Glow effects on accent elements: `0 0 20px rgba(214, 180, 162, 0.4)`
- No harsh, dark shadows (reserved for premium interaction states)

**4. Micro-interactions & Motion**
- Smooth ease-in-out timing: 0.3s - 0.6s transitions
- Hover states: Subtle scale (1.02), glow intensification, soft depth increase
- Scroll reveal: Cards fade in and float up with spring physics
- Gradient animations: Slow, looping background shifts (8s - 12s cycles)
- Hover magnetic effects on buttons and interactive elements
- Premium loading states with skeleton screens

**5. Premium 3D & WebGL Accents**
- Subtle floating particles in hero (non-intrusive)
- Rotating 3D dashboard cards in background
- Ambient light reflections on glass panels
- Soft 3D depth parallax on scroll
- Premium wireframe visualizations in service cards
- Animated metric counters with elegant number transitions
- Light ray effects (subtle, sophisticated)

**6. Gradient Text & Typography Effects**
- Gradient headlines: Purple → Rose-Gold
- Text shadow for depth: `0 4px 12px rgba(0, 0, 0, 0.1)`

## MOTION & INTERACTION SYSTEM

### Animation Philosophy
**Premium, controlled, purposeful motion. Never playful. Always sophisticated.**

### Global Motion Libraries
- **Framer Motion:** Page transitions, section reveals, micro-interactions
- **GSAP:** Complex scroll-based animations, premium timelines
- **Lenis:** Smooth, momentum-based scrolling
- **Three.js / React Three Fiber:** 3D hero elements, floating cards, ambient effects
- **Recharts or D3.js:** Animated charts and data visualizations

### Key Animation Moments

**1. Page Load**
- Fade in from black (0.8s)
- Logo animation (subtle scale-in + glow)
- Staggered section reveals (100ms between elements)
- Gradient background shift (8s loop, subtle)

**2. Scroll-Based Reveals**
- Cards fade in + slide up (spring physics: stiffness 100, damping 15)
- Parallax depth (background moves slower than foreground)
- Gradient text animates on scroll
- Counters tick up when entering viewport
- Charts animate line-by-line or bar-by-bar

**3. Hover Interactions**
- Buttons: Scale 1.02 + glow intensifies + shadow increases
- Cards: Lift +8px + background blur increases + border glow
- Links: Rose-gold color shift + underline animates in
- Icons: Rotate slightly + glow pulse
- Magnetic button effect (cursor influence, small offset)

**4. Form Interactions**
- Input focus: Border glows rose-gold, background tint increases
- Slider changes: Real-time chart updates (0.6s smooth transition)
- Toggle switches: Smooth color transition, scale pulse
- Form submission: Button shows success state (checkmark animation)

**5. Chart Animations**
- Line charts: Draw animation from left to right (2s)
- Bar charts: Grow from bottom (spring physics)
- Gauge charts: Needle sweeps to target value (1.5s)
- Counters: Number ticker with ease-out deceleration

### Timing Standards
- **Quick interactions:** 0.2s - 0.3s (button hover, form focus)
- **Standard transitions:** 0.4s - 0.6s (card reveal, chart update)
- **Cinematic reveals:** 0.8s - 1.2s (section entrance, hero animation)
- **Looping animations:** 8s - 12s (background shifts, gradient loops)

### Motion Easing
- **Entrance:** cubic-bezier(0.34, 1.56, 0.64, 1) — spring bounce
- **Exit:** cubic-bezier(0.25, 0.46, 0.45, 0.94) — smooth ease
- **Continuous:** cubic-bezier(0.25, 0.1, 0.25, 1) — smooth loop
- Prefer: easeInOutCubic, easeOutQuint
